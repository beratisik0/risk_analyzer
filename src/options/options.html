ToS Risk Analyzer Ayarları

LLM API bağlantınızı ve model tercihlerinizi yapılandırın.

API Yapılandırması

API anahtarınız yalnızca cihazınızda (chrome.storage.local) saklanır ve asla sunucuya gönderilmez.

Gelişmiş Ayarlar

LLM yanıtı için maksimum token sayısı. Daha yüksek değerler daha detaylı raporlar üretir.
Düşük değerler (0.0-0.2) daha deterministik ve tutarlı sonuçlar verir. Risk analizi için düşük sıcaklık önerilir.
